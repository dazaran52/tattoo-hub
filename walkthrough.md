### Исправление бага с балансом в админ-панели
- Исправлена логика в `admin.py`, из-за которой прямое изменение баланса (`PUT /api/admin/users/.../balance`) и корректировка (`POST /api/admin/users/.../adjust-balance`) обновляли только поле `balance`, но не `credits`.
- Из-за этого при следующем запросе `GET /users` срабатывал fallback на старое значение `credits`, и баланс визуально "откатывался" обратно.
- Теперь обновление баланса через админку синхронно меняет оба поля, а fallback используется только при отсутствии значения в `balance`.

### Прямая оплата VIP без двойного шага пополнения баланса
- В `payments.py` добавлен специальный пакет `vip_direct` (цена 300 CZK / 12 EUR / 13 USD).
- В `top-up/page.tsx` при недостатке средств для активации VIP пользователь теперь перенаправляется на прямую оплату пакета `vip_direct`, вместо пакета `starter`.
- Webhook Stripe обновлен для корректной обработки `vip_direct`: при успешной оплате пользователь мгновенно получает статус `vip` на 30 дней (при этом средства на баланс кошелька не зачисляются, так как они пошли на оплату статуса).
- Убран дублирующийся вывод баланса внутри кнопки активации, теперь баланс выводится только в шапке страницы `top-up`.
